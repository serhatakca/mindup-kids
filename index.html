🔄 Canlı Senkronizasyon (2 Bilgisayar)
📖 Firebase kurulum adımları (bir kerelik, ~5 dk)
  1. console.firebase.google.com → Google hesabıyla giriş → Proje oluştur (ad: MindUp, Analytics kapalı).
  2. Proje ana sayfasında </> (Web) simgesi → takma ad: MindUp → Kaydet. Çıkan firebaseConfig kodunu kopyalayın.
  3. Sol menü Build → Authentication → Başlayın → E-posta/Şifre'yi etkinleştirin → Users sekmesinden Kullanıcı ekle (örn. mindup@kurum.com + güçlü bir şifre). İki bilgisayar da bu hesapla girecek.
  4. Sol menü Build → Firestore Database → Veritabanı oluştur → bölge seçin → Üretim modu ile başlayın.
  5. Firestore Rules sekmesine şunu yapıştırıp Publish deyin (sadece giriş yapmış kullanıcı okuyup yazar):
    rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if request.auth != null; } } }
  6. Aşağıya firebaseConfig'i yapıştırın, e-posta/şifreyi girin, Bağlan'a basın. Aynı bilgileri ikinci bilgisayarda da girin.

Bu bilgiler yalnızca bu bilgisayarın tarayıcısında saklanır. Mevcut yerel veriler ilk bağlanışta buluta yüklenir ve iki bilgisayarın verisi birleşir.

📅 Google Takvim İki Yönlü Eşitleme
📖 Google Takvim köprüsü kurulumu (bir kerelik, ~2 dk)
  1. script.google.com adresine Google hesabınızla girin ve Yeni proje oluşturun.
  2. Açılan editördeki mevcut kodu silip aşağıdaki kodu yapıştırın (isterseniz SECRET değerini değiştirin):
  3. Sağ üstten Dağıt (Deploy) → Yeni dağıtım (New deployment) tıklayın.
  4. Tür olarak Web uygulaması (Web app) seçin; Yürütülecek kişi: Ben (Me) ve Erişimi olan: Herkes (Anyone) yapıp Dağıt deyin (ilk seferde Google Takvim izni isteyecektir, onaylayın).
  5. Çıkan Web uygulaması URL'sini (https://script.google.com/macros/s/.../exec) aşağıya yapıştırıp Bağlan & Eşitle'ye basın.

MindUp'ta eklenen/güncellenen/silinen seanslar anında Google Takvime işlenir; Google Takvimde yapılan değişiklikler ise açılışta ve her 45 saniyede bir otomatik olarak MindUp'a yansır.
